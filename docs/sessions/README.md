# docs/sessions/ — frozen session snapshots

Point-in-time status dumps from the July 2026 bring-up, kept for history. They
are **not** current and can contradict the live docs (e.g. `TEST_BOOT_NOW.md`
predates `reliable_load.py` and tells you to run `loady_over_acm.py` by hand,
which README now forbids). For the authoritative picture use, in order:
`README.md`, `ROADMAP.md`, then `PROGRESS.md` (the running checkpoint at repo
root). Operating rules live in `SESSION-RULES.md` at the root.
